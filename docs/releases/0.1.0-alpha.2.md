# VoiceBridge 0.1.0-alpha.2

Improved English recognition, verified source installation and an open beta for self-hosted Turkish/English Discord translation.

## Changes

- English recognition uses a more careful deterministic search with the existing pinned local model. Short pauses keep more context; English segments prefer quiet boundaries after six seconds and have a twelve-second hard cap.
- Turkish recognition/capture settings stay unchanged. Consent cancellation, memory limits and per-listener delivery remain in place.
- Source ZIP naming follows the package version, with a per-file SHA-256 manifest. CI extracts the archive, installs new Node dependencies, builds it and checks isolated demo/operator flows.
- Bilingual beta guides and a dedicated feedback form make setup and real-use reports reproducible.

## Try it

Download the source ZIP and verify `SHA256SUMS.txt`. The recorded synthetic demo needs Node 24.17+ / 24.x:

```sh
npm ci --ignore-scripts
npm run build
npm run demo
```

Open `http://127.0.0.1:4348`. Full live setup additionally requires Python 3.12, local models and a dedicated Discord bot: [English setup](../SETUP.md) / [Türkçe kurulum](../SETUP.tr.md).

## Validation and scope

59 TypeScript tests, 9 Python tests, typecheck/build/format and ten browser checks passed locally. A separate extracted installation created a fresh Python environment, reused verified public model-download cache, extracted/verified models and passed the synthetic caption/audio pipeline. The exact release CI/run/archive identity is recorded in the attached `RELEASE-VALIDATION.json` and `CLEAN-INSTALL.json`.

One user confirmed correct English text and Turkish captions after the recognition repair. **Two-person live acceptance and a 5–10-user beta cohort are pending.** The small synthetic speech comparison is not a general accent/accuracy guarantee. Billable-provider calls and multi-user capacity remain unverified; local models can mistranslate times and other details. [Validation](../VALIDATION.md).
